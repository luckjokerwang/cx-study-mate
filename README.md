# 🎓 Chaoxing Study Mate (超星学习助手)

> 专为高校学生打造的跨平台超星/泛雅/尔雅 MOOC 自动化挂课助手。  
> **零依赖配置门槛** · **100% 真实心跳完播** · **扫码即用** · **支持 MOOC1 与新版 MOOC2 智慧课程架构**。

---

## 🌟 核心特性

- ⚡ **零环境配置 + 国内极速镜像**：内置清华大学开源镜像加速（`start.bat` / `start.sh` 自动配置），国内网络 5 秒极速就绪，无需手动安装 Python 或复杂环境变量。
- 🌐 **跨平台原生支持**：
  - **Windows**：纯 ASCII 批处理，双击 `start.bat` 绝无乱码报错，开箱即用；
  - **macOS / Linux**：`./start.sh` 一键运行。
- 📱 **极简手机扫码**：首次启动弹出二维码，打开手机“学习通” App 扫码 5 秒登录，凭证自动保存于本地 `auth.json`，后续永久免密。
- 🎯 **作业测验自主权**：
  - **模式 1（默认推荐）**：纯挂视频模式，自动安全跳过测验，稳妥点亮所有视频绿点；
  - **模式 2（AI 辅助答题）**：自带离线字体反混淆字典，自配 DeepSeek / Qwen 等 Key，自动识别题目并**仅点击【暂存草稿】**，绝不盲目交卷，成绩安全可控。
- 🛡️ **教务风控级安全**：
  - 拒绝暴力发包秒过，完全模拟人类浏览器行为；
  - 坚持 **100% 完整时长播放**并上报合规区间心跳日志，轻松通过学期末教务学习日志审计；
  - 自动静音后台播放，突破切屏暂停与失焦检测限制；
  - 自动识别并作答视频中途弹窗随堂测试题。
- 🔄 **全架构多 Tab 完整轮询**：
  - 深度兼容 `mooc1` 与 `mooc2-ans`；
  - 自动遍历小节顶部的所有 Tab 标签（学习目标 / 视频 / 章节测验），绝不遗漏隐藏标签。
- ⏯️ **智能断点续播**：随时按 `Ctrl + C` 退出，下次启动自动跳过所有已通关视频和作业小节，接着上次进度继续播。

## 🚀 一键使用指南

### 1. Windows 用户（双击即用）
1. 点击 GitHub 仓库右上角 **`Code` -> `Download ZIP`**，将压缩包解压到任意文件夹。
2. 双击打开 **`start.bat`**。
3. 首次使用会自动弹出登录页面，使用手机**学习通 App** 扫码登录。
4. 复制浏览器地址栏中的课程主页网址，粘贴到控制台回车，即刻开始挂播！

---

### 2. macOS / Linux 用户
打开终端执行以下命令：

```bash
git clone https://github.com/luckjokerwang/cx-study-mate.git
cd cx-study-mate
chmod +x start.sh
./start.sh
```

## 💻 进阶命令行运行 (CLI)

如果你习惯使用命令行，也可以直接传入参数：

```bash
# 直接指定课程链接开跑
uv run main.py --url "https://mooc2-ans.chaoxing.com/mooc2-ans/mycourse/stu?courseid=..."

# 从指定小节开始向后播放
uv run main.py --url "..." --start "2.1"
```

## ❓ 常见问题 (FAQ)

### Q1：使用这个脚本会有被教务判定“刷课/异常”的风险吗？
**不会。** 市面上被封禁的脚本大多是因为“1秒秒刷 10 小时视频”，超星后台会直接记录并标红异常时长。本助手在后台真实静音播放视频并按周期上报心跳日志，时长 100% 吻合，与真实观看数据毫无二致。

### Q2：别人用这个脚本需要单独安装 Playwright 或下载浏览器吗？
**不需要。** 脚本会自动探测并复用本机已有的 **Google Chrome** 或 **Microsoft Edge**（Windows 用户自带），无需额外下载 300MB 的 Chromium 内核。

### Q3：换了电脑怎么继续用？
将本文件夹复制到新电脑上，删除 `auth.json`（或重新扫码），即可直接开始使用。
